The daemon loads the model once and keeps it warm in GPU memory, so each utterance costs only inference time. On my machine the graphics card has six gigabytes of memory, which is just enough for the quantized model to run comfortably. When the daemon sits idle for a few minutes, it unloads the model and frees the memory, then reloads it lazily the next time I press the key. The compositor sends the key press to the client regardless of which window is focused, and the client writes a short command to a local socket. Nothing leaves the machine; the audio is captured, transcribed, and typed back into the window entirely offline.
